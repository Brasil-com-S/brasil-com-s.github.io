Documentação para Desenvolvedores

Como integrar a API brasil-com-s na sua aplicação Web, Mobile ou projetos acadêmicos.

Exemplos de Integração

JavaScript (Fetch / Node.js)

fetch('https://brasil-com-s.github.io/api/v1/escolas/rj.json')
  .then(res => res.json())
  .then(data => console.log(data.escolas));

Python (Requests)

import requests

url = "https://brasil-com-s.github.io/api/v1/escolas/mangueira.json"
response = requests.get(url).json()
print(response['data']['titulos'])
